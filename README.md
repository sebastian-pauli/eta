# eta

Functions and data concerning the Dirichlet/Euler eta function

Functions for the computer algebra system Sage (https://www.sagemath.org):

euler_eta.sage contains functions for evaluating the Gruenwald-Letnikov fractional derivatives of eta and some auxiliary function for investigating and plotting them.

euler_eta_example_paths.sage contains examples that illustrate the use of the functions in euler_eta.sage for computing and plotting paths of zeros of fractional derivatives

euler_eta_example_double.sage contains code for finding the double of zero of a fractional derivative of eta
